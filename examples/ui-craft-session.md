# Example: ui-craft session

Goal: design and scaffold a small UI component library for a todo app.

Steps:
1. Load `ui-craft` with prompt: "Create a component library for todo items (React + TypeScript)".
2. `ui-craft` outputs: design tokens, component API, and Figma spec links (placeholder).
3. `dev-craft` can scaffold components, tests, and storybook entries.

Expected artifacts:
- `design-tokens.json` — color, spacing, typography
- `components/` — React components with stories
- `storybook/` — minimal Storybook config

Notes:
- Example assets should use generic placeholders (no external Figma links).
