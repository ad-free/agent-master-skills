# BI / reporting

**Screens:** dashboards with global filters; drill-down; report builder or saved reports; exports; scheduled reports.
**Metrics:** one defined meaning per KPI in a semantic layer or metrics file; show the definition in a tooltip.
**Charts:** lines for time, bars for ranking, tables for detail, avoid dual axes and 3D; consistent colors per category.
**Performance:** caching or materialized views, query limits and timeouts, loading skeletons, filter defaults
that keep queries small.
**Mistakes:** two numbers for the same KPI; unbounded queries; filters that silently reset; no export.
