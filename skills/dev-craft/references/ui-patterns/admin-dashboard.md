# Admin dashboard

**Layout:** sidebar (grouped, collapsible) plus top bar (search, user menu, notifications); breadcrumbs.
**Data tables:** sorting, filtering, pagination (server-side for large data), column visibility, bulk actions,
row actions menu, sticky header, empty and error rows, export.
**Forms:** inline validation, grouped sections, unsaved-changes guard, disabled and loading submit, destructive
actions confirmed.
**Charts:** lines for trends, bars for comparisons, donut for few parts; legend, units, empty/loading states
(`idioms/charts.md`).
**Mistakes:** every page a raw table; no filters preserved in the URL; actions with no feedback; no
permission-denied view; inconsistent spacing.
