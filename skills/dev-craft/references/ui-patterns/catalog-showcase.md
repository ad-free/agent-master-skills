# Catalog / showcase site (for example a PPE product site)

**Structure:** hero with one clear call to action; category navigation; product grid of image cards; filters
(category, standard, size); product detail with specs table, images, downloads and certifications; news/blog
list; contact page with form, map and validation; trust elements (standards, certifications, clients).
**Product card:** image, name, 1-line benefit, standard badge; consistent aspect ratio, lazy images.
**Product detail:** gallery, key specs, certificate download, related products, "request a quote".
**Forms:** labeled fields, inline validation, spam protection, success state, email delivery verified.
**SEO and performance:** titles and meta per page, semantic headings, alt text, sitemap, responsive images.
**Mistakes:** stock photos with no product focus, spec data as images, no mobile nav, contact form with no
confirmation, missing certification evidence.
